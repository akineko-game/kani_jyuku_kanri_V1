# SDS拡張コンポーネント v5 — 組み込み手順

## ファイル構成

```
sds-component/
  component.js   — コンポーネント本体（IIFE形式・ダミーデータ入り）
  component.css  — スコープ付きCSS（.sds-root 配下のみ適用）
  demo.html      — 組み込みデモ
  README.md      — 本ファイル
```

---

## 組み込み手順

### 1. ファイルを既存サイトに設置

```
your-site/
  component.js
  component.css
  your-page.html
```

### 2. HTMLに追記

```html
<!-- headタグ内 -->
<link rel="stylesheet" href="component.css">

<!-- bodyタグ内（マウント先） -->
<div id="sds-component"></div>

<!-- bodyタグ閉じる直前 -->
<script src="component.js"></script>
<script>
  SDS.initComponent({ mountElement: '#sds-component' });
</script>
```

## 機能一覧

| タブ | 機能 | 概要 |
|------|------|------|
| 講師管理 | 複数講師の登録・状態管理 | 稼働開始/休止/退職/削除。稼働中の講師が講師割当に自動反映 |
| 講師割当 | 稼働中の講師をセレクトで選択 | 未選択時はエラー表示。両方揃うと通知を自動作成 |
| 教室管理 | 複数教室の登録・状態管理 | 使用開始/停止/削除。使用可能教室が教室割当に自動反映 |
| 教室割当 | 使用可能な教室をセレクトで選択 | 未選択時はエラー表示。両方揃うと通知を自動作成 |
| 通知 | 通知管理 | トースト表示＋メール文面モーダル生成（コピー可）。講師+教室割当済・満席で自動作成 |
| 連絡先 | 保護者連絡先CRUD | 名前・電話・メールを登録・削除 |
| 連絡履歴 | 通知送信履歴 | 送信のたびに自動記録。クリア可能 |
| 月謝調整 | 生徒別月謝計算 | 科目単価＋コース単価＋学年単価の加算方式。生徒を登録して自動計算 |
| 座席制御 | 授業コマ予約管理 | コマ登録・生徒予約・空き状況可視化。月謝タブの生徒をセレクトで選択可 |
| 設定反映 | 設定影響範囲管理 | 反映対象コンポーネントをチェックで選択 |

---

## 画面間連携

```
[1] 講師管理（稼働）     → 講師割当のセレクトに自動反映
[2] 教室管理（使用可能） → 教室割当のセレクトに自動反映
[3] 講師＋教室 両方割当済 → 通知タブが自動で「通知予定」状態に
[4] 座席制御で満席        → 通知タブが自動で「通知予定」状態に
[5] 月謝タブの生徒リスト → 座席制御の予約セレクトに流用
```

---

## 月謝計算式

```
月謝 = 科目単価 ＋ コース単価 ＋ 学年単価
```

例：数学（週2回・中3）= ¥5,000 ＋ ¥3,000 ＋ ¥2,000 = **¥10,000**

## EventBus API（外部連携）

```javascript
// イベント購読
SDS.EventBus.on('store:teachers-updated', function(payload) {
  console.log('稼働講師リストが更新されました', payload);
});

// 主なイベント一覧
// store:teachers-updated  — 講師の稼働状態が変化
// store:rooms-updated     — 教室の使用状態が変化
// store:both-assigned     — 講師＋教室が両方割当済に
// store:seat-full         — 授業コマが満席に
// store:students-updated  — 月謝タブの生徒リストが変化
// store:history-updated   — 連絡履歴が追加
```

## 技術仕様

| 項目 | 内容 |
|------|------|
| 実装形式 | IIFE（即時実行関数式）— グローバルスコープ汚染なし |
| 依存ライブラリ | なし（Vanilla JS） |
| グローバル公開 | `window.SDS.initComponent` と `window.SDS.EventBus` のみ |
| CSSスコープ | `.sds-root` 配下のみ適用 |
| データ永続化 | なし（ページリロードでリセット） |
| ブラウザ対応 | モダンブラウザ全般 |
| 通知手段 | 画面内トースト＋メール文面生成（外部送信なし） |
