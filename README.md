# SDS拡張コンポーネント — 組み込み手順

## ファイル構成

```
sds-component/
  component.js   — コンポーネント本体（IIFE形式）
  component.css  — スコープ付きCSS（.sds-root 配下のみ適用）
  demo.html      — 組み込みデモ
  README.md      — 本ファイル
```

---

## 組み込み手順

### 1. ファイルを設置

既存ホームページのディレクトリに `component.js` と `component.css` を配置します。

### 2. CSSを読み込む

```html
<link rel="stylesheet" href="/path/to/component.css">
```

### 3. マウント先要素を用意

```html
<div id="sds-component"></div>
```

### 4. スクリプトを読み込む

```html
<script src="/path/to/component.js"></script>
```

### 5. 初期化

```javascript
SDS.initComponent({
  mountElement: '#sds-component',  // CSSセレクタまたはDOM要素
  options: {}
});
```

## EventBus API

他システムとのイベント連携は `SDS.EventBus` を使用します。

```javascript
// イベント購読
SDS.EventBus.on('teacher:稼働開始', function(payload) {
  console.log('講師が稼働開始しました', payload);
});

// イベント発火（外部から）
SDS.EventBus.emit('teacher:稼働開始', { state: '稼働中' });
```

### 定義済みイベント一覧

| イベント名                 | 発生タイミング         |
|--------------------------|----------------------|
| `teacher:講師登録`        | 講師を新規登録         |
| `teacher:稼働開始`        | 講師が稼働状態へ       |
| `teacher:休止処理`        | 講師が休止状態へ       |
| `teacher:退職処理`        | 講師が退職             |
| `teacher-assign:講師割当` | 講師を予約へ割当       |
| `teacher-assign:講師割当解除` | 割当を解除         |
| `room:教室登録`           | 教室を新規登録         |
| `room:教室使用開始`       | 教室が使用中状態へ     |
| `room-assign:教室割当`    | 教室を予約へ割当       |
| `notification:通知送信`   | 通知を送信             |
| `seat:予約枠確保`         | 座席を1件確保          |
| `seat:予約枠解放`         | 座席を1件解放          |
| `settings:影響範囲確認`   | 設定の影響確認         |

## 動作確認項目

### 講師管理
- [ ] 未登録 → 名前入力 → 登録 → 登録済 状態へ遷移するか
- [ ] 登録済 → 稼働開始 → 稼働中 状態へ遷移するか
- [ ] 稼働中 → 休止 → 休止中 状態へ遷移するか
- [ ] 稼働中 → 退職 → 退職済 状態になり操作不可になるか
- [ ] 無効遷移（未登録 → 稼働開始 など）がログに記録されブロックされるか

### 講師割当
- [ ] 未割当 → 割当 → 割当済 状態へ遷移するか
- [ ] 割当済 → 解除 → 未割当 状態へ遷移するか

### 教室管理
- [ ] 未登録 → 登録 → 使用可能 状態へ遷移するか
- [ ] 使用可能 → 使用開始 → 使用中 状態へ遷移するか

### 座席制御
- [ ] 予約枠確保を繰り返すと満席状態になるか
- [ ] 満席時に「解放」ボタンが表示されるか
- [ ] プログレスバーが使用率に応じて変化するか

### 通知
- [ ] 未通知 → 通知予定作成 → 通知予定 状態へ遷移するか
- [ ] 通知予定 → 送信 → 送信済 状態へ遷移するか
- [ ] 通知予定 → キャンセル → 未通知 状態へ遷移するか

### 設定反映
- [ ] 要確認 → 影響範囲確認 → 確認済 状態へ遷移するか
- [ ] 確認済 → 反映除外 → 除外済 状態になり操作不可になるか

### 共通
- [ ] 全状態遷移がログエリアに記録されるか
- [ ] Undefined表示が各コンポーネントに正しく出ているか
- [ ] 既存ページのCSS/JSに影響がないか（グローバルスコープ確認）

## 技術仕様

- **実装形式**: IIFE（即時実行関数式）
- **依存ライブラリ**: なし
- **グローバル公開**: `window.SDS.initComponent`, `window.SDS.EventBus` のみ
- **CSS スコープ**: `.sds-root` 配下のみ適用
- **ブラウザ対応**: モダンブラウザ全般（ES5+）
